# Mlondolozi.dev Private Brand Assets

This folder contains reusable private logo and email signature assets based on the current Mlondolozi.dev visual identity.

- `logo-square.svg` - square MZ monogram for avatars, app icons, and social profile images.
- `logo-rectangular.svg` - wide logo lockup for headers, banners, and email signature use.
- `logo.svg` - primary transparent SVG logo lockup.
- `email-signature.html` - HTML email signature using the rectangular logo beside it in this folder.

Keep this folder outside `public` so these files are not deployed as public website assets.
